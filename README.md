Lightweight Cryptography in IoT - ASCON-128

This project explores the implementation and performance of **ASCON-128**, a lightweight authenticated encryption algorithm designed for devices with limited resources, such as IoT devices and wireless sensors.

The project uses Python to implement encryption and decryption and evaluate the algorithm through different tests.

 What’s included

* ASCON-128 encryption and decryption.
* Ciphertext tampering and associated data validation tests.
* Encryption/decryption timing and throughput measurements.
* Memory usage analysis.
* Avalanche effect testing and performance experiments.

Purpose

The aim is to understand how ASCON-128 works and evaluate its efficiency, correctness, and suitability for resource-constrained environments.

**Language:** Python

**Project type:** Cybersecurity/Cryptography research
